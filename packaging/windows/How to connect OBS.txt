VAN LINK - CONNECTING OBS (one time, on each computer)
======================================================

Van Link controls OBS through OBS's own remote-control feature.
Turn it on once:

1. Open OBS Studio (version 28 or newer).
2. Click Tools > WebSocket Server Settings.
3. Tick "Enable WebSocket server". Leave the port as 4455.
4. Click "Show Connect Info" and copy the Server Password.
5. Open Van Link > Settings > paste it into "OBS WebSocket password" > Save.

The top of the Van Link screen then shows "OBS connected".


STUDIO COMPUTER
---------------
1. Open Van Link and choose "This is the Studio".
2. Click "Add a van". Send the code to the van (Copy or Share on WhatsApp).
3. Paste the reply code the van sends back, then click Connect.
4. In OBS, a scene called "Van Link" appears with the van's source.
   Add that source to your programme scenes with Add > Existing.


VAN COMPUTER
------------
1. Open Van Link and choose "This is the Van".
2. Paste the studio's code and click Pair.
3. Send the reply code back to the studio.
4. When the screen says "Connected", click GO LIVE.
   Van Link sends OBS's Program output. "LIVE AT STUDIO" appears
   once the studio confirms it is receiving your picture.


DOCK THE MONITOR INSIDE OBS (optional)
--------------------------------------
In OBS: View > Docks > Custom Browser Docks.
Name: Van Link    URL: http://127.0.0.1:8765/?dock=1
